# ARMOS overlay

Custom ebuilds for the ARMOS distribution:

- `app-admin/armos-welcome` — first-run welcome app
- `app-admin/armos-center` — settings hub
- `app-admin/armos-store` — application catalog / Portage frontend
- `app-admin/armos-updater` — system update GUI
- `x11-themes/armos-branding` — logo, wallpapers, themes, GRUB/LightDM assets
- `sys-apps/armos-live` — live user, autologin, persistence helpers
- `app-admin/armos-calamares` — Calamares config + post-install
- `app-misc/armos-meta` — meta package for the full desktop
